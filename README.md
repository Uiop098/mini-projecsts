# Road Rush 🚗

A simple top-down endless car game built with plain HTML, CSS and JavaScript (canvas). No dependencies.

## Play

Open `index.html` in any browser, or play online via GitHub Pages (Settings → Pages → deploy from `main` branch, root).

## Controls

- Move: `←` `→` or `A` `D` (on-screen buttons on touch devices)
- Pause: `P`
- Start / restart: button or `Enter`

## How it works

- Dodge oncoming traffic; the road speeds up as your score grows.
- Your best score is saved in the browser (`localStorage`).

## Files

- `index.html` – page layout
- `style.css` – styling
- `game.js` – game loop, rendering, input, collisions
